# Governance Playbook Backup

This folder is a GitHub backup of the cross-project governance system.

## Contents
- `MVP_MILESTONE_GOVERNANCE_STANDARD.md`: Milestone governance standard.
- `skills/project-kickoff/`: Reusable kickoff skill package.
  - `SKILL.md`
  - `agents/openai.yaml`
  - `references/default-file-priority.md`

## Reuse Steps
1. Copy `skills/project-kickoff/` into your account-level skills directory.
2. Copy `MVP_MILESTONE_GOVERNANCE_STANDARD.md` into the target project docs.
3. Start each project or milestone with the kickoff template confirmation.
