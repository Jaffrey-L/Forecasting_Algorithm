## 新增功能

### 1. 增强日志记录与告警机制
**文件**: `src/forecasting/logging_alert.py`

**新特性**:
- 增强日志记录器（EnhancedLogger）
- 详细运行日志记录
- 关键异常告警
- 日志分析功能

**使用示例**:
```python
from src.forecasting.logging_alert import EnhancedLogger

logger = EnhancedLogger(log_dir='logs', log_level='INFO')
logger.log_forecast_start(spu='SPU001', mode='smart', exog_cols=['ad_cost', 'price'])
logger.log_data_quality(spu='SPU001', data_points=100, missing_rate=0.05, trend='upward', seasonality='strong')
logger.log_model_selection(spu='SPU001', models=[...])
logger.log_forecast_end(spu='SPU001', elapsed_time=12.5, wmape=0.15, algo='Prophet')
```

### 2. 预测误差自动报警
**文件**: `src/forecasting/error_alert.py`

**新特性**:
- 误差阈值配置
- 报警规则（WMAPE超阈值、异常高、连续超阈值）
- 报警通知
- 告警摘要

**使用示例**:
```python
from src.forecasting.error_alert import ErrorAlertManager

alert_manager = ErrorAlertManager(db_url='postgresql://...', wmape_threshold=0.30)
report = alert_manager.run_error_alerts(
    spu='SPU001',
    wmape=0.45,
    historical_wmapes=[0.15, 0.18, 0.20, 0.22, 0.25],
    sku_metrics={...},
    model_results=[...]
)
```

### 3. SKU准确性评估优化
**文件**: `src/forecasting/sku_accuracy_optimized.py`

**新特性**:
- 优化的SKU准确性评估逻辑
- 性能优化（向量化计算）
- 评估报告生成
- 阈值优化

**使用示例**:
```python
from src.forecasting.sku_accuracy_optimized import calculate_sku_accuracy_optimized

result = calculate_sku_accuracy_optimized(
    actual=actual_df,
    pred=pred_df,
    sku_accuracy_threshold=0.01
)
```

### 4. 交互式图表增强
**文件**: `src/forecasting/interactive_charts.py`

**新特性**:

### 5. 数据库性能优化
**文件**: `src/database/optimization.py`

**新特性**:
- 索引优化
- 查询优化
- 缓存策略
- 插入优化

**使用示例**:
```python

optimizer = DatabaseOptimizer(db_url='postgresql://...', pool_size=10, max_overflow=20)
```

### 6. SKU份额预测模型
**文件**: `src/forecasting/sku_share_prediction.py`

**新特性**:
- 份额预测模型（多种方法：动态回归、随机森林、XGBoost、LightGBM、简单指数移动平均）
- 份额调整
- 份额验证

**使用示例**:
```python
from src.forecasting.sku_share_prediction import SKUSharePredictor

predictor = SKUSharePredictor(method='dynamic_regression')
predictor.fit(sku_sales_history)
future_shares = predictor.predict(n_steps=4)
sku_forecast = predictor.predict_with_spu_forecast(spu_forecast, n_steps=4)
```

## 升级路径

### 从 v1.3.x 升级到 v1.4.0

1. **安装新依赖**:
```bash
pip install plotly
```

2. **更新数据库**:
```sql
-- 创建告警表（如果不存在）
CREATE TABLE IF NOT EXISTS forecasting_alerts (
    alert_id VARCHAR(255) PRIMARY KEY,
    alert_type VARCHAR(100),
    spu VARCHAR(50),
    severity VARCHAR(20),
    message TEXT,
    details JSONB,
    created_at TIMESTAMP,
    status VARCHAR(20)
);
```

3. **更新配置**:
```python
# 在 main.py 中添加新功能
from src.forecasting.logging_alert import EnhancedLogger
from src.forecasting.error_alert import ErrorAlertManager
from src.forecasting.interactive_charts import InteractiveChartGenerator
from src.database.optimization import DatabaseOptimizer
```
