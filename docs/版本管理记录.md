## 版本管理规范

### 版本号格式

```
主版本号.次版本号.修订号
```

- **主版本号**: 大版本更新，可能包含不兼容的API变更
- **次版本号**: 功能更新，向后兼容
- **修订号**: Bug修复，向后兼容

### 发布流程

1. **代码审查**: 所有代码需经过至少一名同事审查
2. **测试验证**: 确保所有测试通过
3. **文档更新**: 更新版本管理记录和需求文档
4. **版本标记**: 在代码仓库创建Tag
5. **发布说明**: 发布版本说明文档

### 回滚策略

- 如遇严重问题，可回滚到上一稳定版本
- 回滚前需备份当前版本数据
- 回滚后需记录问题和原因
