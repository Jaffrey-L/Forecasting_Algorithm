# 预测准确性监控模块

## 模块概述

预测准确性监控模块用于监控预测准确性，实现WMAPE阈值监控、误差趋势分析和告警机制。

## 功能特性

### 1. WMAPE阈值监控
- 实时监控预测WMAPE值
- 自动检测超过阈值的预测
- 阈值可配置（默认30%）

### 2. 异常检测
- 检测WMAPE超阈值异常
- 检测WMAPE异常高（超过平均值3倍标准差）
- 异常详情记录

### 3. 趋势分析
- WMAPE趋势分析（7天移动平均）
- 模型性能趋势分析
- 趋势变化百分比计算

### 4. 告警机制
- 生成告警记录
- 告警严重级别（HIGH/MEDIUM）
- 告警保存到数据库

## 使用方法

### 基本使用

```python
from src.forecasting.monitor import ForecastingMonitor

# 创建监控器
monitor = ForecastingMonitor(
    db_url='postgresql://user:password@localhost:5432/dbname',
    wmape_threshold=0.30
)

# 运行监控
result = monitor.run_monitoring(days=30)

# 获取报告
report = monitor.get_monitoring_report(days=30)
print(report)
```

### 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| db_url | str | 必填 | 数据库连接URL |
| wmape_threshold | float | 0.30 | WMAPE阈值 |

## 数据库表结构

### forecasting_alerts 表

```sql
CREATE TABLE forecasting_alerts (
    alert_id VARCHAR(255) PRIMARY KEY,
    alert_type VARCHAR(50) NOT NULL,
    spu VARCHAR(50) NOT NULL,
    run_date DATE NOT NULL,
    severity VARCHAR(10) NOT NULL,
    message TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 注意事项

1. 确保数据库连接正确配置
2. WMAPE阈值可根据业务需求调整
3. 监控频率建议每天运行一次
4. 异常检测基于统计方法，可能存在误报
5. 告警保存到数据库前会检查是否存在重复
