# 算法前后对比验证口径（不加新数据）

## 目标
- 固定同一数据源、同一 SPU 范围、同一运行模式。
- 仅对比两个代码版本（`baseline_ref` vs `optimized_ref`）效果差异。
- 输出可复查的结果文件与统一解读模板。

## 入口脚本
- `tools/analysis/run_baseline_vs_optimized.py`

## 推荐命令

### 1) 小样本冒烟（先确认流程）
```bash
python tools/analysis/run_baseline_vs_optimized.py \
  --baseline-ref HEAD~1 \
  --optimized-ref HEAD \
  --mode smart \
  --max-spus 10 \
  --db-url "$SALES_FORECAST_DB_URL" \
  --tag ab_smoke
```

### 2) 指定 SPU 对比（问题复盘）
```bash
python tools/analysis/run_baseline_vs_optimized.py \
  --baseline-ref HEAD~1 \
  --optimized-ref HEAD \
  --mode smart \
  --spu-list 0887,1318,3063,3072,3075 \
  --db-url "$SALES_FORECAST_DB_URL" \
  --tag ab_focus
```

### 3) 全量口径（正式评估）
```bash
python tools/analysis/run_baseline_vs_optimized.py \
  --baseline-ref HEAD~1 \
  --optimized-ref HEAD \
  --mode smart \
  --db-url "$SALES_FORECAST_DB_URL" \
  --tag ab_full
```

## 输出文件
- `reports/generated/<tag>_baseline_result.json`
- `reports/generated/<tag>_optimized_result.json`
- `reports/generated/<tag>_compare_result.json`
- `reports/generated/<tag>_interpretation_template.md`

## 指标字段定义（统一口径）

### summary 级
- `sample_count`：成功产出验证结果的 SPU 数
- `failure_count`：执行失败或未产出结果的 SPU 数
- `mean_wmape_pct`：SPU 级验证 WMAPE 均值（百分比）
- `median_wmape_pct`：SPU 级验证 WMAPE 中位数（百分比）
- `p75_wmape_pct`：SPU 级验证 WMAPE 75 分位（百分比）
- `p90_wmape_pct`：SPU 级验证 WMAPE 90 分位（百分比）
- `gt40_count`：`validation_wmape > 40%` 的 SPU 数
- `gt50_count`：`validation_wmape > 50%` 的 SPU 数
- `winner_distribution`：胜出算法分布

### compare 级
- `comparison_scope.common_spu_count`：两边都成功的可比 SPU 数
- `headline.mean_wmape_delta_pct`：`baseline - optimized` 的均值差（百分点，正值代表优化变好）
- `headline.improved_count / worsened_count / same_count`：SPU 维度改进/变差/持平数量
- `per_spu[].delta_wmape_pct`：单 SPU 差值（百分点，正值代表优化变好）

## 结果解读模板（执行后直接套用）
1. 先看稳定性（硬门槛）
- `optimized.sample_count >= baseline.sample_count * 0.95`
- `optimized.failure_count <= baseline.failure_count`
- `optimized.gt50_count <= baseline.gt50_count`

2. 再看质量（软目标）
- `mean_wmape_pct` 下降
- `median_wmape_pct` 下降
- `p75_wmape_pct` / `p90_wmape_pct` 下降
- `gt40_count` 下降

3. 结论模板
```text
在同一数据、同一SPU范围、同一运行模式下：
- 覆盖变化：{sample_delta}
- 平均误差变化：{mean_delta}
- 长尾变化：{tail_delta}
- SPU层：improved={improved} / worsened={worsened} / same={same}
结论：{通过 / 有条件通过 / 不通过}
后续动作：{列出需要重点回看的SPU与算法}
```
