# 首页线框说明（`/`）

## 1. 页面定位
任务执行页。目标是让用户在首屏完成：
1) 选择 SPU；
2) 启动任务；
并立即看到运行反馈。

## 2. 区块结构（从上到下）
- 顶部总览条：
  - 页面标题
  - 当前系统状态（空闲/运行中）
  - 最近任务标识
- 主工作区（左右两栏）：
  - 左栏（任务发起，主区）
    - 运行模式选择
    - SPU 选择模式切换（all/manual/sql）
    - 输入区（manual 或 sql）
    - 主按钮：启动任务
    - 次按钮：预览 SPU
    - 停止按钮：仅 running/stopping 显示
  - 右栏（运行状态，反馈区）
    - 任务状态标签
    - 进度条
    - 已处理/总数、成功数、当前 SPU
    - 快速日志入口
- 结果区（折叠优先）：
  - 结果摘要（模型、平均 WMAPE、成功/失败计数）
  - 结果明细表（默认次级）
- 辅助区（页面底部）：
  - 配置模板
  - 执行计划
  - SPU 状态明细
  - 日志流

## 3. 关键文案规范
- `all`：默认全量 SPU。
- `manual`：支持逗号、空格、换行。
- `sql`：仅允许单列 `spu` 的 SELECT。
- 空态：给“下一步操作建议”，不能只写“暂无数据”。
- 错误态：显示用户可行动提示（修正输入/重试）。

## 4. 交互路径（MVP）
1. 默认进入 `all`。
2. 用户可切换 `manual` 或 `sql` 并点击“预览 SPU”。
3. 点击“启动任务”后，按钮进入 loading 并禁止重复提交。
4. 状态区轮询更新，进度和当前 SPU 实时变化。
5. 完成后自动强化显示结果摘要，明细可继续查看。
