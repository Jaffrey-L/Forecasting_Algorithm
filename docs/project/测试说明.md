# SPU预测分析系统测试说明

## 测试环境
- 浏览器：Chrome、Firefox、Edge等现代浏览器
- 无需后端服务器，前端已集成模拟后端服务

## 测试步骤

### 1. 启动系统
1. 打开 `index.html` 文件（直接在浏览器中打开）
2. 等待页面加载完成，确保所有组件都正常显示

### 2. 测试预测功能
1. **选择模式**：从下拉菜单中选择预测模式（smart、fast、accurate）
2. **选择数据库写入**：选择是否启用数据库写入
3. **点击开始预测**：点击"开始预测"按钮
4. **观察进度**：
   - 进度条应该开始增长
   - 状态应该显示为"运行中"
   - 实时日志应该显示预测过程
   - 应该显示当前处理的SPU和已处理的SPU数量
5. **观察算法运行**：实时日志应该显示每种算法的运行情况和WMAPE值
6. **等待完成**：预测完成后，状态应该显示为"完成"

### 3. 测试停止功能
1. 在预测运行过程中，点击"停止预测"按钮
2. 观察预测是否停止，状态是否更新

### 4. 测试分析功能
1. 预测完成后，点击"生成分析报告"按钮
2. 观察加载状态
3. 等待分析完成，查看生成的分析报告
4. 检查报告中是否包含：
   - 数据概览
   - 预测趋势图
   - 模型性能分析
   - 预测结果表格

### 5. 测试算法切换
1. 在分析报告页面，点击不同的算法标签（Prophet、XGBoost等）
2. 观察图表是否切换到对应算法的预测结果

### 6. 测试响应式设计
1. 调整浏览器窗口大小
2. 检查页面布局是否在不同尺寸下正常显示

## 预期结果

### 功能预期
1. **预测启动**：点击"开始预测"按钮后，系统应该开始模拟预测过程
2. **实时进度**：进度条应该实时更新，显示预测的当前进度
3. **实时日志**：日志区域应该实时显示预测过程的详细信息
4. **预测完成**：预测完成后，状态应该更新为"完成"，并显示最终结果
5. **分析报告**：点击"生成分析报告"按钮后，应该生成包含图表和数据的分析报告
6. **算法切换**：点击不同的算法标签，应该显示对应算法的预测结果
7. **响应式设计**：页面应该在不同尺寸的浏览器窗口中正常显示

### 性能预期
1. 页面加载时间：< 3秒
2. 预测启动响应时间：< 1秒
3. 分析报告生成时间：< 3秒
4. 算法切换响应时间：< 1秒

## 注意事项
1. 本系统使用模拟后端服务，所有数据均为模拟数据
2. 预测过程中的算法运行和WMAPE值均为随机生成
3. 分析报告中的图表和数据也是基于模拟数据生成的
4. 系统不需要外部后端服务器，可直接在浏览器中运行

## 测试完成标准
1. 所有功能都能正常运行，无错误提示
2. 界面美观，布局合理
3. 响应式设计正常工作
4. 性能满足预期要求
