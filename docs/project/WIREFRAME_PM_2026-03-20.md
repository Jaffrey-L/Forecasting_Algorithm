# PM 页线框说明（`/pm`）

## 1. 页面定位
项目管理决策页。目标是让管理视角快速判断：
- 当前是否在 MVP 轨道上；
- 门禁是否通过；
- 下一步唯一优先动作是什么。

## 2. 区块结构（从上到下）
- 顶部决策头：
  - 当前里程碑目标（SPU MVP 闭环）
  - 门禁通过率
  - 当前阶段
  - 复制项目总结按钮
- 范围边界区：
  - 本阶段要做
  - 本阶段不做
- 验收门禁区：
  - 门禁项
  - 状态（通过/部分通过/未通过）
  - 备注（阻塞点或证据）
- 每日推进看板：
  - TODO / DOING / DONE / RISK / BLOCKED
- 下一步任务区：
  - 仅列 1~5 条最关键动作（按优先级）

## 3. 信息表达规则
- 所有列表项必须可执行、可验收，禁止空泛描述。
- 状态色只用于门禁和风险，不用于装饰。
- RISK 与 BLOCKED 必须可追踪到具体任务或证据。
- “下一步”始终按 P0 优先。

## 4. 使用规范
1. 每次里程碑推进前先更新“范围边界”。
2. 每次回归后更新“门禁状态”与“阻塞项”。
3. 每日汇报直接基于本页内容输出，不另起口径。
4. 里程碑结束时将本页关键信息沉淀到复盘文档。
