# 任务上下文卡

正式分派前，先整理这张卡。

## 模板

### 任务背景
- 为什么要做
- 要解决什么问题

### 当前状态
- 现在做到哪
- 已有结果是什么

### 关键文件
- 只放真正相关的文件
- 默认控制在 3 到 8 个

### 关键约束
- 不能动什么
- 必须遵守什么
- 有哪些固定口径

### 已知风险
- 当前最可能出问题的地方
- 当前最影响交付的地方

### 验收口径
- 什么叫通过
- 什么叫不通过
- 谁做任务级验收
- 小C如何做最终交付级验收

## 使用规则

- 先整理上下文卡，再分派专家
- 上下文不清楚时，先补上下文，不直接执行
- 不把整仓库内容一股脑塞给专家
- 只给当前任务真正需要的上下文
- 默认把验收分层写清楚
  - 任务级验收是谁
  - 最终总验收是谁
