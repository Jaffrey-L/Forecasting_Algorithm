# 任务启动清单

每次新任务开始，先按这个格式输出。

## 模板

### 主线目标
- 这次要解决什么问题

### 交付标准
- 最后要交什么
- 交到什么程度

### 验收标准
- 什么情况算完成
- 什么情况不算完成

### 团队分工
- 小C：
- 按任务复杂度和涉及专业填写，不强行把所有角色都写满
- 最低必须写清：
  - 谁执行
  - 谁做任务级验收/审查
  - 小C怎么做最终总验收

### 并行策略
- 哪些可以同时做
- 哪些要等前置结果

### 预期产出
- 代码
- 文档
- 测试结果
- 风险清单

## 使用规则

- 先发这份清单，再正式开工
- 没有任务启动清单，就不正式开工
- 没有对齐交付和验收标准，不分派任务
- 没有想清楚，不进入正式执行
- 团队配置按任务决定，但任何任务最低 2 人推进
- 小C永远是最终交付级总验收
- 默认语言简单直接
- 默认验收偏严格
