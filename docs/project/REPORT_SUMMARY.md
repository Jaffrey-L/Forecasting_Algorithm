# SPU 销售预测引擎升级与验证结果汇报

## 1. 核心目标
解决原有“单 SKU 预测”模式在数据稀疏、波动剧烈场景下准确率低的问题，通过**“SPU 总量预测 + 动态 SKU 拆分”**的新策略，提升备货决策的科学性。

## 2. 我们做了什么 (What We Did)

### 2.1 策略升级：Top-Down 预测体系
- **弃用**：不再对每个 SKU 单独建模（因长尾 SKU 噪音太大，预测几乎不可用）。
- **采用**：
    1. **SPU 聚合**：将同款商品的所有变体销量聚合为 SPU 总量序列，消除随机波动，捕捉宏观趋势。
    2. **模型竞赛**：引入 Prophet、XGBoost、LSTM 等多种模型对 SPU 总量进行“赛马”，自动选出 WMAPE 最小的胜者。
    3. **动态拆分**：基于 SKU 的历史销量占比趋势，将 SPU 预测值拆回 SKU 级别。

### 2.2 算法与工程落地
- **数据治理**：清洗异常值、断货填充，并将最小训练样本门槛优化至 12 周，覆盖更多新品。
- **验证闭环**：在每次预测时，自动回测（Backtesting）最后 4-10 周数据，计算 SPU 与 SKU 的真实误差。
- **系统集成**：预测结果直接写入数仓（PostgreSQL），并提供 SKU 级误差明细视图，支持 BI 直接看板展示。

## 3. 最终验证结果 (Validation Results)

基于 SPU `0887`（及其他抽样 SPU）的实测数据，我们得出了强有力的结论：

### 3.1 SPU 预测高度精准
- **SPU 级误差 (WMAPE)**：仅 **9.8%**（准确率 > 90%）。
- **结论**：SPU 聚合后的曲线平滑、规律性强，模型能非常准确地捕捉未来的销量趋势。**SPU 级预测值完全可作为备货总量的核心依据。**

### 3.2 SKU 预测误差的分层现象（重要发现）
实测数据表明，SKU 级误差并非“全员不可用”，而是存在显著的**两极分化**：

| SKU 类型 | 特征描述 | 验证误差 (WMAPE) | 结论 |
| :--- | :--- | :--- | :--- |
| **热卖 SKU (主力)** | 销量高、占比稳定、曲线连续 | **40% ~ 60%** (部分<40%) | **具备参考价值**：虽然不如 SPU 准，但大方向基本正确。 |
| **长尾 SKU (尾部)** | 销量低、断续、波动剧烈 | **> 400%** (甚至 800%) | **完全不可信**：主要受偶发波动（如断货、退货）干扰，严重拉高了整体平均误差。 |

**洞察**：
我们之前看到的“SKU 整体误差大”，主要是被长尾 SKU 的极端值拉高了。对于占据 80% 销量的**主力 SKU**，模型预测其实表现尚可。

### 3.3 最终结论
- **SPU (总量)**：误差仅 **9.8%**，精准度极高。
- **SKU (结构)**：热卖款尚可，长尾款失真。

| 维度 | 准确性评价 | 业务指导意义 |
| :--- | :--- | :--- |
| **SPU (总量)** | ⭐⭐⭐⭐⭐ (极高) | **直接采纳**：作为备货资金、产能规划的刚性依据。 |
| **热卖 SKU** | ⭐⭐⭐ (中等) | **辅助参考**：作为配比基准，结合库存微调。 |
| **长尾 SKU** | ⭐ (较低) | **需人工介入**：建议按最低陈列量或试销策略备货，不依赖预测。 |

## 4. 后续预测与业务建议 (Next Steps)

基于上述验证结果，我们建议采取 **“总量信模型，配比重人工”** 的人机结合模式：

### 4.1 备货决策流程
1.  **定总量 (Trust the Model)**：
    *   直接采用算法输出的 **SPU 未来 16 周预测总量**。
    *   理由：90%+ 的准确率远超人工拍脑袋，能有效控制库存周转与资金占用。

2.  **调配比 (Human in the Loop)**：
    *   以算法提供的“SKU 拆分比例”为基准线。
    *   由业务人员结合**当前库存水位、断码情况、促销计划**进行微调。
    *   理由：算法难以捕捉“某尺码因断货导致销量为 0”的业务归因，人工修正能补齐这一短板。

### 4.2 持续优化计划
- **监控报警**：每周监控 SPU 预测误差，一旦 WMAPE > 30% 自动报警，人工介入排查（如大促、刷单干扰）。
- **新品策略**：对于样本 < 12 周的新品，不强行预测，建议采用“对标品”或“试销”策略。
- **归因分析**：后续将引入“库存因子”进入模型，尝试解决因缺货导致的 SKU 占比失真问题。

---
**总结**：本次升级成功验证了“聚合预测”的有效性。我们已经掌握了一套能精准预测 **SPU 总量** 的自动化工具，这将显著提升供应链的抗风险能力。
