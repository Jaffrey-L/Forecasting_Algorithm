# 版本管理记录

## v1.3.1 (2026-03-24)

### 发布日期
2026-03-24

### 主要功能
1. **Prophet模型修复**：将Prophet从多进程执行改为单进程执行，解决Windows多进程兼容性问题
2. **环境变量配置**：在algorithm_engine.py文件开头设置Prophet环境变量，确保stan_backend正确初始化
3. **NumPy版本兼容**：降级NumPy到1.26.4版本，解决与TensorFlow的兼容性问题
4. **错误日志增强**：增强模型失败时的错误日志输出，便于问题诊断

### 修复内容
- **Prophet 'stan_backend'错误**：在config_and_utils.py的_mp_worker函数中设置STAN_BACKEND和CMDSTANPY_COMPILE环境变量
- **Windows多进程编译问题**：将Prophet改为单进程运行，避免多进程环境下每个子进程都尝试编译导致的冲突
- **NumPy 2.0+兼容性**：解决`np.float_`被移除的问题，使用`np.float64`代替
- **TensorFlow兼容性**：升级NumPy到1.26.4，确保与TensorFlow 2.13.0的兼容性

### 测试结论
- API服务成功启动并运行在http://0.0.0.0:8000
- 所有模型（Prophet、XGBoost、LightGBM、SARIMA等）均能正常执行
- 前端页面可以正常访问并与API交互
- 预测结果能正确存储到数据库

### 部署建议
1. **环境配置**：确保NumPy版本为1.26.4，避免使用NumPy 2.0+
2. **运行环境**：在Windows环境下，Prophet将以单进程模式运行；在Linux环境下，可根据需要调整为多进程模式
3. **监控**：定期检查API服务运行状态，确保所有模型正常执行

### 后续计划
1. **生产环境部署**：在Linux生产环境中部署时，可考虑恢复多进程执行以提高性能
2. **模型优化**：持续优化模型参数，提高预测准确性
3. **监控系统**：完善监控系统，及时发现和处理异常情况
